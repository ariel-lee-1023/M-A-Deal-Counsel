# M&A Deal Counsel

An agent skill for structuring M&A issue spotting and work plans from two reference texts. It is designed for transaction teams that need a repeatable way to connect strategy, process, valuation, risk allocation, approvals, financing, and integration.

## Use

Ask the skill a concrete deal question, such as:

- "Build a diligence-to-risk-allocation matrix for a cash acquisition."
- "Pressure-test the synergy case and premium."
- "What should counsel put on the critical path before signing?"
- "Compare a full acquisition, alliance, and divestiture for this capability."

Always supply the jurisdiction, transaction form, parties' roles, deal stage, and the decision needed. This library is a planning tool; it requires current-law and current-market verification by appropriate professionals.

## Source record

Included, distilled without verbatim copying:

- Patrick A. Gaughan, *Mergers, Acquisitions, and Corporate Restructurings* (Markdown source; 16 chapters).
- Donald M. DePamphilis, *Mergers, Acquisitions, and Other Restructuring Activities: An Integrated Approach to Process, Tools, Cases, and Solutions* (10th ed., Markdown source; 18 chapters).

Not included in the agent-loaded references because the supplied copies were image-only scans with no usable text layer:

- Claire A. Hill, Brian Jose Miguel Quinn et al., *Mergers and Acquisitions Law, Theory, and Practice* (835-page PDF).
- Dale Arthur Oesterle et al., *The Law of Mergers and Acquisitions* (1,002-page PDF).

To fold either excluded book in later, OCR it into a searchable PDF (or provide a reliable text/Markdown conversion), re-run the book extraction, create one additional `references/reference-<slug>.md`, and update the router and cross-book topic index. Do not treat this README as an agent-loaded legal source.

## Limits

The textbook material includes historical U.S.-oriented legal, tax, accounting, regulatory, and market discussion. Those elements may be superseded. Confirm all live legal, regulatory, tax, accounting, disclosure, and financing conclusions using current primary materials and appropriately qualified advisors.
